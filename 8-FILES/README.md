## 1. deploy.sh (для опытных пользователей)

Файл быстрой базовой настройки и защиты сервера `Linux Ubuntu` с автоматическим развертыванием `Docker` и системы `RustDesk`. Скрипт выполняет следующие действия:

- Интерактивный сбор данных: Безопасно запрашивает имя нового пользователя, пароль и публичный `SSH`-ключ.
- Умное обновление системы: Полностью обновляет пакеты `Ubuntu` в тихом режиме без всплывающих интерактивных окон.
- Настройка `SWAP`: Принудительно очищает старые лимиты хостинга и создает честный файл подкачки на `1ГБ`.
- Защита брандмауэром `UFW`: Закрывает все лишние порты, оставляя открытыми только SSH порт `22`, веб-трафик `80`, и порты для работы `RustDesk`.
- Безопасность `SSH`: Полностью отключает авторизацию по паролям и закрывает прямой доступ для пользователя `root`. Вход возможен только по личному `SSH`-ключу под новым созданным пользователем.
- Автоматизация `Docker`: Устанавливает `Docker`, добавляет пользователя в общую группу и прописывает системную `cron`-задачу на каждый понедельник в `00:00` для автоматической и бесшумной очистки диска от старых кэшей и неиспользуемых образов (`docker system prune`).

Для запуска необходимо загрузить файл `deploy.sh` по `SFTP` на чистый сервер в домашнюю директорию `root` пользователя.

Выдать права доступа:

```bash
chmod +x deploy.sh
```

Запустить скрипт:

```bash
./deploy.sh
```
